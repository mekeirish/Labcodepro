# 🧪 Labcode | La Sandbox Réactive

> Propulsé par **Mekeirish** • Partie de *The Code Suite*

Labcode est le laboratoire d'expérimentation de la suite. C'est un espace isolé conçu pour jeter, tester et valider des composants React, des scripts dynamiques ou des animations CSS en temps réel avant leur déploiement.

## 🔮 Interface & Design
*   **Charte Graphique :** `The Code Suite - Strict` (Matte Cyber & Soft UI).
*   **Coloris :** Séparation hermétique entre le Panneau Technique (Matte Cyber sombre) et le miroir de rendu. Bouton d'exécution pulsant en Violet Électrique, console de logs en Jaune Cyber.
*   **Layout :** Split-screen asymétrique. Éditeur à gauche, conteneur de preview isolé à droite via une ombre portée marquée.

## 🚀 Fonctionnalités Clés
*   **Rendu Isolé :** Iframe de prévisualisation neutre garantissant qu'aucune feuille de style externe ne vient fausser l'expérience de test.
*   **Console de Log Intégrée :** Capture en direct des logs et erreurs JavaScript directement au bas du tableau de bord.
*   **Exécution à la Volée :** Injection et rafraîchissement dynamique du code sans rechargement de la page.
